# منصة التعلم الفردي الذكي — Intelligent Personalized Learning Platform

منصة تقيس مستوى المتدرب في تخصص تقني بتقييم تكيفي (قياس المهارة ثم قياس المعرفة)، وتحلل الفجوات، ثم تبني رحلة تعليمية لكل فجوة: إحاطة تشرح (ليش مهم ← أنا أشرح ← نسوي سوا ← تأكد سريع)، ثم نشاط تطبيقي من خمسة (غرفة الهروب، صياد الفجوات، تحديات من واقع العمل، الظل والظل العكسي، علّم غيرك)، ثم إعادة قياس مستقلة وتقرير قبل/بعد. الأسئلة والمحتوى يولّدها الذكاء الاصطناعي وفق برومبتات في `backend/prompts/`.

> المنصة تحتاج **خادم Python** (FastAPI): لا تعمل على استضافة ملفات ثابتة فقط مثل Netlify أو GitHub Pages.

## التشغيل على جهازك

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m backend.set_api_key        # يطلب المفتاح بشكل مخفي ويحفظه في .env
uvicorn backend.main:app --reload    # ثم افتح http://localhost:8000
```

الاختبارات: `pytest -q`

## النشر على Render (الخادم والواجهة معًا)

1. ادخل [render.com](https://render.com) بحساب GitHub.
2. **New → Blueprint**، واختر هذا المستودع؛ يقرأ Render ملف `render.yaml`.
3. أدخل القيم السرية عندما تُطلب:
   - `OPENAI_API_KEY`: مفتاح OpenAI.
   - `ACCESS_CODE`: رمز دخول تختاره؛ كل من يفتح الرابط يُطلب منه (اسم المستخدم أي شيء، وكلمة المرور هي الرمز).
4. بعد اكتمال النشر يعطيك Render رابطًا مثل `https://intelligent-learning-platform.onrender.com`.

ملاحظات الخطة المجانية: الخدمة تنام بعد فترة خمول فيتأخر أول طلب، وقاعدة البيانات (SQLite) لا تبقى بعد إعادة التشغيل أو إعادة النشر — مناسبة للتجربة، وللاستخدام الدائم يلزم قرص دائم أو قاعدة بيانات مُدارة.

## الأمان

- مفتاح الذكاء الاصطناعي في الخادم فقط (`.env` محلّيًا، ومتغيرات البيئة عند النشر)، ولا يُرسل للمتصفح ولا يُرفع إلى Git.
- `ACCESS_CODE` يمنع الغرباء من استخدام المنصة واستهلاك رصيد المفتاح.

## البنية

- `backend/`: الخادم — التقييم التكيفي (`assessment_engine.py`, `adaptive_selector.py`)، تحليل الفجوات (`gap_analyzer.py`)، الإحاطة (`lesson.py`)، الأنشطة (`activity_core.py` + ملف لكل نشاط)، تتبع السلوك (`behavior.py`)، إعادة القياس (`reassessment.py`).
- `backend/prompts/`: كل البرومبتات، قابلة للتعديل دون تغيير الكود.
- `frontend/`: الصفحات (HTML/CSS/JavaScript).
- `tests/`: اختبارات بذكاء اصطناعي وهمي (بلا تكلفة).
